## ✨ Fitur Unggulan

- **Responsive Design:** Tampil sempurna dan mulus di berbagai perangkat (Desktop, Tablet, Mobile).
- **Dark/Light Mode:** Kenyamanan mata pengguna dengan opsi pergantian tema otomatis maupun manual.
- **Interactive Portfolio:** Menampilkan proyek-proyek unggulan lengkap dengan filter kategori dan tautan langsung.
- **About Me Section:** Ruang cerita singkat mengenai latar belakang, perjalanan karier, dan *passion*.
- **Tech Stack Showcase:** Menampilkan daftar teknologi, bahasa pemrograman, dan *tools* yang dikuasai.
- **Contact Form / Direct Link:** Integrasi formulir pesan langsung dan tautan cepat ke sosial media profesional (LinkedIn, GitHub, Email, dll).

---

## 🛠️ Tech Stack (Teknologi yang Digunakan)

Proyek ini dibangun menggunakan teknologi modern untuk memastikan performa yang cepat dan optimal:

* **Frontend:** HTML5, CSS3 / Tailwind CSS, JavaScript (Vanilla / React.js)
* **Icons:** FontAwesome / Lucide Icons
* **Deployment:** Vercel / Netlify / GitHub Pages
* **Version Control:** Git & GitHub
